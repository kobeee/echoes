## 二、全局性系统问题（跨页面）

### 2.1 🔴 Inter 字体残留（4 个节点）

**属性搜索确认**：`fontFamily` 仍有 `Inter` 值存在。

| 节点 ID | 名称 | 页面 | 当前字体 |
|---------|------|------|---------|
| `GNmvV` | footprintIcon (👣) | Main Map TabBar | Inter |
| `ZnSm5` | footprintLabel (足迹) | Main Map TabBar | Inter |
| `YFop9` | settingsIcon (⚙️) | Main Map TabBar | Inter |
| `HS00u` | settingsLabel (设置) | Main Map TabBar | Inter |

**修复操作**: `replace_all_matching_properties` 将 `fontFamily: "Inter"` → `"-apple-system"`

### 2.2 🔴 圆角体系不统一（12 种值）

当前全局存在的 cornerRadius 值：`0, 1, 2, 3, 4, 10, 12, 14, 18, 22, 24, 28`

**建议标准化为 5 级体系**:
| Token | 值 | 用途 |
|-------|-----|------|
| `radius-xs` | 2 | 进度条、波形条 |
| `radius-sm` | 4 | 小元素（信号条、进度块） |
| `radius-md` | 12 | 卡片、按钮、输入框 |
| `radius-lg` | 22 | Widget、大容器 |
| `radius-full` | 9999 | 胶囊按钮、圆形 |

需清理的异常值：`1`（加密卡描边圆角）、`3`（信号条）、`10`（埋藏选项按钮）、`14`（location badge 和 toggle）、`18`（Dynamic Island）、`24`（Live Activity）、`28`（解锁按钮）

### 2.3 🔴 可复用组件仍为 0

所有页面的 TabBar、NavBar、按钮等相同结构都是独立复制，无法跨页面同步修改。这是**设计系统的根基缺失**。

**当前 TabBar 存在于**：Main Map、Settings、My Footprints、Empty Map（共4处）  
**问题**：每处 TabBar 结构和内容都不一致
- Main Map TabBar (`3YoWo`): 完整 5 标签 ✅
- Settings TabBar (`stTabBar`): 完整 5 标签 ✅ 但 y:935 **超出页面 852pt 高度**
- My Footprints TabBar (`A5nMV`): **仅 1 个空 frame** ❌
- Empty Map TabBar (`emTabBar`): **完全空内容** ❌

### 2.4 🟡 字号体系（19 种值）

当前使用的字号：`11, 12, 13, 14, 15, 16, 17, 18, 20, 22, 24, 28, 32, 34, 36, 40, 48, 56, 64`

iOS 标准语义字号映射：
| iOS Type Style | 标准字号 | 当前使用 | 状态 |
|---------------|---------|---------|------|
| Large Title | 34pt | 34pt | ✅ |
| Title 1 | 28pt | 28pt | ✅ |
| Title 2 | 22pt | 22pt | ✅ |
| Title 3 | 20pt | 20pt | ✅ |
| Headline | 17pt Semibold | 17pt | ✅ |
| Body | 17pt | 17pt | ✅ |
| Callout | 16pt | 16pt | ✅ |
| Subheadline | 15pt | 15pt | ✅ |
| Footnote | 13pt | 13pt | ✅ |
| Caption 1 | 12pt | 12pt | ✅ |
| Caption 2 | 11pt | 11pt | ✅ |

**非标准字号需审查**：`14pt`（可归入 Subheadline 15pt）、`18pt`（介于 17pt Body 和 20pt Title 3 之间，建议统一为 17pt）、`36pt`/`40pt`/`48pt`/`56pt`/`64pt`（展示用特殊字号，可保留）

### 5.3 关键齐整度问题

#### 问题 A: 设置页内容溢出 🔴

**根因分析**:
```
stHeader:     y:0,     h:100  → 底: 100
stProfile:    y:120,   h:100  → 底: 220 (gap: 20)
stPro:        y:240,   h:140  → 底: 380 (gap: 20)
stPrivHeader: y:400            → (gap: 20)
stPrivGroup:  y:425,   h:132  → 底: 557 (gap: 25)
stNotifHeader:y:575            → (gap: 18)
stNotifGroup: y:600,   h:88   → 底: 688 (gap: 25)
stAboutHeader:y:708            → (gap: 20)
stAboutGroup: y:733,   h:176  → 底: 909 🔴 超出 852
stTabBar:     y:935,   h:83   → 底: 1018 🔴 超出 852
```

**修复方案**: 页面高度改为 1020pt（可滚动），或遵循 IFLOW 视觉稿第一原则"滚动内容完整展示"

#### 问题 B: 足迹页下半页空白 🟡

**根因分析**:
```
fpHeader:    y:0,   h:100    → 底: 100
fpStats:     y:120, h:80     → 底: 200
fpTimeline:  y:220, h:400    → 底: 620 (但只有 2 条记录，实际内容 ~160pt)
实际内容底边约 y:400
页面底边 y:852，空白 452pt（53%）
fpTabBar:    y:769, h:83     → 底: 852 (但内容为空)
```

**修复方案**: 
1. 增加更多足迹记录条目（3-5 条）来填充时间线
2. 添加足迹地图预览卡片（v2.1 审查建议的）
3. 填充 TabBar 内容

#### 问题 C: 黑匣子中段拥挤 🟡

计时器区域(y:320-420) 与状态文字(y:400) 和进度条(y:480) 之间的间距不均匀。
建议重新分配垂直空间，使脉冲/计时器/状态/进度/加密卡的间距均匀。
