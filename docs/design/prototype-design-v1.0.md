# 回响 (Echoes) iOS App 原型设计方案 v1.0

## 一、设计概述

### 1.1 产品定位
- **名称**: 回响 (Echoes / GeoTrace)
- **Slogan**: 只有身临其境，才能听见回响
- **平台**: iOS 19+ (iPhone)

### 1.2 设计理念
- **极简主义**: 无社交压力，无点赞关注，只有"埋藏"与"拾取"
- **隐私至上**: 无账号体系，基于 Device ID 和 iCloud Keychain
- **系统共生**: 通过 Siri 和 Widget 完成 80% 的交互

### 1.3 视觉风格
- **主色调**: 深邃黑 (#0A0A0F) + 暖金色 (#D4AF37)
- **强调色**: 信号青 (#00D9C0) - 用于雷达、定位
- **警示色**: 紧急红 (#FF3B30) - 用于黑匣子模式
- **设计风格**: Dark Mode 为主，极简主义，科幻感与温暖并存

### 3.1 启动页 (Launch Screen)

**布局**:
- 全屏深色背景 #0A0A0F
- 中央: 动态波形 Logo

- 开启动画: 波形从中心扩散
