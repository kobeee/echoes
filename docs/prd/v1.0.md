【产品设计方案 C - 进化版】

产品名称：回响 (Echoes / GeoTrace)
Slogan：只有身临其境，才能听见回响。
平台：iOS 19+ (iPhone, Apple Watch), visionOS (可选)

一、 产品定位与核心逻辑
1. 极简主义 (Minimalism)：无社交压力，无点赞关注。只有“埋藏（Drop）”与“拾取（Pickup）”。
2. 隐私至上 (Privacy First)：无账号体系（No Login），基于 Device ID 和 iCloud Keychain 验证。
3. 系统共生 (System Integrated)：不强迫用户打开 App，通过 Siri 和 Widget 完成 80% 的交互。

二、 深度系统融合 (The Apple Ecosystem Integration)

1. App Intents (Siri & Spotlight)
   - 意图 A：快捷埋点 (DropIntent)
     - 语音指令：“Siri，在这留个话。” / “Siri, leave a note here.”
     - 交互：Siri 唤醒后台服务，记录当前 GPS，并在后台开始录音/听写。
     - 参数：自动识别当前时间、地点、天气作为元数据。
   - 意图 B：紧急信标 (EmergencyTraceIntent)
     - 语音指令：“Siri，开启黑匣子模式。” (自定义短语)
     - 交互：静默启动摄像头和麦克风，录制 30 秒环境信息，上传至云端“SOS 坐标”，随后本地自动清除缓存。
   - 意图 C：雷达扫描 (ScanIntent)
     - 场景：用户问“附近有什么留言吗？”，Siri 直接以 Snippet（卡片）形式展示周围 500 米内的公开 Echoes 列表，无需进入 App。

2. WidgetKit & Live Activities (桌面与锁屏)
   - 桌面组件 (The Compass)：
     - 静态展示：显示最近一次“埋点”的距离和方向（如：距离上次埋下的‘给未来的信’还有 3km）。
     - 交互按钮：点击组件上的“+”直接进入录制界面（利用 iOS 17+ 的 Interactive Widgets 特性）。
   - 实时活动 (Live Activities - 寻宝模式)：
     - 当用户锁定了一个附近的 Echoes 进行追踪时，灵动岛（Dynamic Island）和锁屏显示实时雷达：
       - 左侧：距离倒数（50m -> 10m）。
       - 右侧：信号强度波形。
       - 背景：当距离 < 5m 时，整个实时活动区域发出微弱的金色呼吸光效。

三、 核心功能详解

模块 1：埋藏 (The Drop) - 发布者
- 内容形式：
  - 轻量级（免费）：文字便签、60秒语音。
  - 重量级（付费/订阅）：4K 视频、全景照片。
- 权限设置：
  - 公开 (Public)：所有路人可见。
  - 加密 (Private)：生成 4 位数字密码或“口令”。路人能看到这里有东西，但必须输入口令才能解锁（适合情侣/密室游戏）。
- 时间锁 (Time Lock - 核心付费点)：
  - 设定“开启时间”。例如：“2030年才能打开”。
  - 价值：利用区块链或不可篡改的服务器时间戳，确保存储承诺。

模块 2：拾取 (The Pickup) - 寻觅者
- 被动感知：App 后台运行（利用 Core Location 的 Geofencing）。当进入某个高价值 Echo 的 20 米范围内，Apple Watch 给予独特的“心跳”震动反馈。
- 主动挖掘：
  - 拿出手机，Widget 显示“发现信号”。
  - 点击进入，雷达界面指引方向。
  - 解锁内容：对于视频/大文件，需确认“下载并查看”。
- 互动：
  - 仅限“已阅（Witnessed）”标记。不做评论区，防止网络暴力。

模块 3：黑匣子 (The Black Box / SOS) - 安全
- 触发：通过 Siri 快捷指令或 App 内的红色紧急按钮。
- 逻辑：
  - 极速上传：视频流分片上传，确保即使手机下一秒被毁，前几秒的数据已在云端。
  - 阅后即焚（本地）：上传完成后，本地 App 内不留任何记录（相册无痕、发布记录无痕）。
  - 证据提取：只能通过特定网页端，输入设备唯一密钥（Recovery Key）才能找回这段数据。

四、 内容安全与审核 (Safety & Moderation)

1. 端侧智能 (CoreML On-Device)
   - 在上传发生 *之前*，利用 iOS 的 Neural Engine 进行本地推理。
   - 视觉模型：识别裸露、血腥、枪支刀具等敏感画面。
   - 文本/语音模型：识别明显的辱骂、仇恨言论。
   - 机制：如果本地模型判定违规 > 90%，直接拦截上传，提示“内容不适宜”。

2. 云端分级 (Cloud Classification)
   - 对于模糊地带的内容（如仅仅是吵架但无暴力），标记为“NSFW (Not Safe For Work)”，默认折叠，查看需二次确认。
   - 对于 SOS 模式上传的内容，不做自动拦截（因为可能是暴力证据），但默认锁定，不进入公开地图流。

五、 隐私设计 (Privacy by Design)
- 零知识身份：不要求手机号注册。用户身份 = 设备 ID + iCloud 令牌。
- 数据隔离：
  - “我的足迹”保存在本地数据库。
  - “公共埋点”保存在云端，但剥离上传者信息，只保留时间戳和地理坐标。

六、 商业化模式 (Monetization)

1. 基础版 (Free)
   - 查看所有公开内容。
   - 发布文字/语音。
   - 此时此地（无时间锁）。

2. 存储付费 (Pay for Storage/Time)
   - 视频上传券：￥1.00/条（支付流量与云存储成本）。
   - 时间胶囊券：￥5.00/条（承诺保存 5 年以上，并在到期日发送推送）。

3. 订阅制 (Echoes Pro) - ￥12/月
   - 附近的秘密地图（解锁大范围热力图）。
   - 无限次视频上传。
   - 拥有专属的地图图标（如金色的光点）。
